# Synology File Station 预览插件（空格/ESC + 视频/音频/图片）

项目初衷：在群晖的File station整理文件时，经常会遇到不规范命名的情况，例如：“29548_raw.mp4”、“IMG_0898.HEIC”、“IMG_20210718_180002.jpg”等情况，要么需要下载到本地查看，要么通过预览查看。但是预览需要操作太繁琐，有些视频文件还需要右键播放，但是加载特别缓慢。为解决此问题，固开发本插件。

本项目是一个针对群晖 DSM7.2.2系统 File Station 套件的浏览器扩展：选中文件按空格即可在页面内浮层预览（视频/音频/图片），按 ESC 关闭；支持上下键在同目录媒体间切换、视频快进快退、图片滚轮缩放和拖拽移动。可按域名（含端口）开关是否启用，避免影响其他站点。

- 兼容 Chromium 内核浏览器（Chrome/Edge 等），Manifest V3。
- 版本：1.2.0

## 功能特性
- 空格快速预览、ESC关闭预览
- 上/下方向键在媒体文件间无缝切换（浮层不关闭）
- 视频：支持 `mp4/m4v/mov/webm/mpeg` 等，`m3u8` 通过 HLS 播放（Safari 原生或 hls.js）
- 音频：支持 `mp3/aac/m4a/ogg/oga/opus/wav/flac`，自动解析 MP3 ID3 标题/艺人/专辑与封面，带旋转唱片视觉效果
- 图片：支持 `jpg/jpeg/png/gif/webp/bmp/svg/heic/heif`，HEIC 自动转 JPEG 预览（本地转换，不上传）
- 站点粒度开关：按 `host:port` 控制是否启用扩展
- 无外部服务依赖：所有处理在本地浏览器完成

## 支持格式（概览）
- 视频：`mp4, m4v, mov, webm, mpg, mpeg, mkv, flv, ts, m3u8`
- 音频：`mp3, aac, m4a, oga, ogg, opus, wav, flac`
- 图片：`jpg, jpeg, png, gif, webp, bmp, svg, heic, heif`
> 注：具体可播能力受浏览器编解码支持影响；不支持的格式会提示并回退。

## 安装
1. 克隆或下载本项目到本地（无构建步骤）。
2. 打开 Chrome 或 Edge：
   - 访问 `chrome://extensions/`（Edge 为 `edge://extensions/`）
   - 打开“开发者模式”
   - 点击“加载已解压的扩展程序”，选择本项目根目录
   - 在选项中，配置自己nas的域名及端口使扩展生效

安装完成后，浏览器工具栏会出现扩展图标。

## 配置（按域名/端口启用）
1. 在扩展管理页点击本扩展的“详细信息” → “扩展选项”
2. 在“域名列表（支持 host:port）”中添加你的 DSM/File Station 访问地址：
   - 示例：`nas.example.com:5001`、`10.0.0.2:5000`、或无端口 `files.example.com`
3. 保持“生效”打勾后保存。仅当当前页面的 `host:port` 在列表中且启用时，扩展才会注入功能。
4. 返回 File Station 页面并刷新。

## 使用方法
- 选中一个媒体文件（视频/音频/图片），按空格打开浮层预览；按 ESC 关闭。
- 浮层开启时：
  - 上/下方向键：切换到上一/下一媒体文件（保持浮层不关闭）
  - 左/右方向键（视频）：快退/快进 10 秒
  - 空格：播放/暂停（视频/音频）
- 图片预览：鼠标滚轮缩放、按住拖拽移动。
- 音频预览：自动读取 MP3 ID3，显示标题/艺人/专辑和封面，并带唱片动画。

> 首次捕获直链可能失败：若提示“未捕获直链…”，请在 File Station 中右键任意媒体并点击一次“在新标签中打开/播放”，再尝试空格预览。

## 工作原理（简述）
- 预注入资源：通过 `manifest.json` 的 `content_scripts` 预置 Plyr、HLS、HEIC 转换脚本及样式，规避 DSM CSP 限制。
- 直链捕获：注入 `page-hook.js` 到页面上下文，临时拦截 File Station 内部的 `window.open` 调用获取真实直链；扩展端以编程方式触发右键菜单并点击“在新标签中打开/播放”。捕获过程中隐藏菜单元素，避免闪烁。
- 预览浮层：构建遮罩层并在其中嵌入 Plyr（或原生）播放器/图片视图；结合预加载、键盘控制和音频 ID3 解析，提供流畅的无跳页预览体验。

## 常见问题（FAQ）
- 扩展未生效？
  - 确认在“选项页”中已添加并启用了当前 `host:port`。
  - 刷新 File Station 页面；必要时重开标签页。
- 按空格没有反应或提示未捕获直链？
  - 先右键任意媒体文件并点击一次“在新标签中打开/播放”，再试。
- HLS（m3u8）无法播放？
  - 可能是跨域或鉴权导致的加载失败；尝试在同源下访问或使用支持的浏览器。Safari 通常可原生播放 m3u8。
- 图片（HEIC）无法预览？
  - 浏览器将先下载并在本地转换为 JPEG 以展示；若资源跨域拦截或网络异常，可能会回退为原图尝试显示。
- 仍能看到右键菜单一闪而过？
  - 已加入静默隐藏策略；若仍出现，请描述浏览器版本、DSM 版本和可复现步骤以便定位。

## 权限与隐私
- 仅使用 `storage` 权限保存你的 `host:port` 列表与启用状态。
- 页面权限匹配 `http/https` 用于注入 File Station 相关页面，无数据回传至外部服务器。

## 目录结构
- `manifest.json`：扩展清单（MV3），声明注入脚本与样式
- `content.js`：核心逻辑（捕获直链、浮层预览、键盘导航、预加载、ID3 解析等）
- `page-hook.js`：运行在页面上下文，拦截 `window.open` 回传直链
- `lib/`：第三方与样式资源（`plyr.*`、`hls.min.js`、`heic2any.min.js`、`fs-preview.css`）
- `icons/`：扩展图标
- `options.html` / `options.js`：站点启用开关的选项页

## 开发与调试
- 本项目无构建步骤，直接以“加载已解压的扩展程序”方式安装。
- 建议在 File Station 页面打开开发者工具（F12）观察 Console/Network。
- 若你准备二次开发：
  - 保持第三方库通过 `manifest` 预注入，避免运行时注入被 CSP 拦截。
  - 注意在预览浮层生命周期内清理事件监听与对象 URL，避免内存泄漏。
